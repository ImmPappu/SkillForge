# SkillForge 🚀

A personalized student skill development platform to help students track skills, follow learning roadmaps, manage projects, and monitor their progress.

## Features

- 🎯 Learning Roadmap
- 🧠 Skill Tracking
- 📝 Assessments
- 🚀 Project Management
- 👤 Student Profile
- 📊 Progress Dashboard

## Tech Stack

React • Vite • JavaScript • Supabase
