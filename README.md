# SkillForge 🚀

SkillForge is a student skill development platform that helps students track their technical skills, manage projects, follow learning roadmaps, take assessments, and monitor their overall progress.

## Features

- 👤 Student Profile
- 🧠 Skill Tracking
- 🗺️ Learning Roadmap
- 🚀 Project Management
- 📝 Assessments
- 📊 Progress Dashboard
- ☁️ Supabase Database & Storage

## Tech Stack

React • Vite • JavaScript • Supabase

## Future Plans

Gemini AI integration will be added to provide personalized roadmaps, AI-generated assessments, and learning recommendations based on each student's goals, skills, and progress.
